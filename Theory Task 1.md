Поліморфізм — механізм ООП, який дозволяє об'єктам різних класів (нащадків одного базового класу) по-різному реагувати на виклик методу з однаковим ім'ям при зверненні через вказівник або посилання на базовий клас.

Невіртуальні та віртуальні методи (раннє та пізнє зв'язування):
Невіртуальний метод (раннє зв'язування): вибір методу відбувається на етапі компіляції залежно від типу вказівника чи змінної. Якщо через вказівник базового класу (Base*) звернутися до об'єкта класу-нащадка (Derived), викликається невіртуальний метод базового класу (Base), а не нащадка.

Віртуальний метод (virtual, пізнє / динамічне зв'язування): вибір методу відбувається під час виконання програми залежно від реального типу об'єкта в пам'яті, на який вказує вказівник або посилання на базовий клас.

Абстрактні класи та чисто віртуальні методи:
Чисто віртуальний метод (pure virtual): метод базового класу без реалізації, оголошений із = 0 (наприклад, virtual double magnitude() const = 0;).

Абстрактний клас: клас, який містить хоча б одну чисто віртуальну функцію. Створити екземпляр абстрактного класу напряму неможливо, але можна створювати вказівники та посилання на нього для поліморфної роботи з об'єктами класів-нащадків, які зобов'язані перевизначити всі чисто віртуальні методи бази.

Перезавантаження операторів:Механізм, що дозволяє визначити власну поведінку стандартних операторів C++ (+, -, ==, << тощо) для користувацьких класів.

Оператори можна перевантажувати як методи класу (лівим операндом є *this, наприклад +, ==) або як вільні/дружні функції (friend, наприклад потоковий оператор виводу <<, де лівим операндом виступає std::ostream).

Оператори, які не перевантажуються у C++: :: (визначення області видимості), . (доступ до члена), .* (доступ до члена через вказівник), ?: (тернарний оператор)
